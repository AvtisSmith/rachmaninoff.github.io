# «Рахманинов 150»

Многостраничная цифровая выставка к 150-летию со дня рождения Сергея Васильевича Рахманинова (1873–2023). Проект выполнен на чистых HTML5, CSS3 и JavaScript, не использует внешние библиотеки, шрифты, трекеры или сетевые медиаресурсы.

## Страницы

| Файл | Содержание |
| --- | --- |
| `index.html` | Главная экспозиция, маршруты чтения и ключевые даты |
| `biography.html` | Пять периодов биографии и хронология из 12 дат |
| `works.html` | Каталог 10 произведений с поиском, фильтром и сортировкой |
| `media.html` | Локальная медиаколлекция с полноэкранным диалогом |
| `legacy.html` | События юбилейного 2023 года и викторина |
| `sources.html` | Проверяемая библиография, примечания и медиакредиты |
| `member.html` | Персональный слушательский маршрут без регистрации |

## Возможности

- адаптивное меню для мобильных экранов;
- светлая и тёмная темы;
- клавиатурно доступные вкладки периодов биографии;
- поиск, жанровый фильтр и три режима сортировки произведений;
- сохранение выбранных произведений в памяти браузера и печать маршрута;
- диалог просмотра изображений с возвратом фокуса;
- викторина из пяти вопросов с объяснением каждого ответа;
- skip-link, заметный фокус, семантические ориентиры, `aria-live` и поддержка `prefers-reduced-motion`;
- локальные оптимизированные превью, метаописания, `robots.txt` и `sitemap.xml`.

## Запуск

Требуется Node.js 18 или новее. В каталоге проекта выполните:

```powershell
npm run serve
```

После этого откройте `http://127.0.0.1:8000`. Сайт также работает при прямом открытии `index.html`, но локальный сервер точнее воспроизводит публикацию.

## Проверка

```powershell
npm test
npm run check
```

Тесты используют только встроенные модули Node.js. Они проверяют структуру всех страниц, локальные ссылки и ресурсы, уникальность идентификаторов, состав каталога, доступность, сигнатуры изображений и SEO-файлы.

## Источники и права

Факты сверены с Большой российской энциклопедией, архивным описанием Library of Congress, порталом «Культура.РФ», музеем Московской консерватории и Rachmaninoff Network. Полные ссылки и пояснения к спорным датам приведены на странице `sources.html`. Исходные изображения сохранены локально; при неизвестной атрибуции это указано прямо. Перед публичной публикацией необходимо подтвердить права на каждую цифровую копию.

## Публикация

Перед размещением на реальном домене замените `http://localhost:8000` в `sitemap.xml` и `robots.txt` на канонический адрес сайта. Сервер `scripts/serve.mjs` предназначен для локальной проверки, а статические файлы можно размещать на любом обычном веб-хостинге.
